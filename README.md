# Hawelia Logistics Website

Static GitHub Pages website for Hawelia Logistics.

## Publish on GitHub Pages
1. Create a public GitHub repository, e.g. `hawelia-logistics`.
2. Upload all files and folders in this directory.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will publish the site at `https://YOUR-USERNAME.github.io/hawelia-logistics/`.

The website contains no server-side code or paid dependencies.
